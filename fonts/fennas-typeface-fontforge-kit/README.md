# Fennas Typeface Family — kit FontForge

Ce paquet contient les **sources SVG**, les métriques, les spécifications de
dessin et les scripts FontForge nécessaires pour produire localement une famille
typographique destinée à MERP UI.

## Faces fournies

- Fennas Roman Regular
- Fennas Roman Bold
- Fennas Text Regular
- Fennas Text Italic
- Fennas Text Bold
- Fennas Small Caps Regular
- Fennas Initials Regular
- Fennas Runes Regular

## Important

Ce kit ne contient pas de fichier TTF, OTF ou WOFF compilé. Utilisez FontForge
localement pour les générer.

- `docs/DESIGN-SPECIFICATION.md`
