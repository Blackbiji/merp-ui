# MERP-UI 1.6.0 RC4 — Review release

**Unofficial, free, non-commercial Foundry VTT module for Rolemaster Unified (RMU).**

This RC4 is intended for public testing and for review by interested authors and rights holders. It is not an official MERP or RMU product.

### Improvements
- French and English support for 187 Herbs & Substances, plus seven descriptive French herb names.
- Improved labels for seasonal ranges, special dates, moon phases, weather-dependent collection windows and plant forms.
- High-contrast, compact headings in character-creation Talent descriptions.
- Compendium-first content model (9 Compendiums, 455 documents), with source/seed synchronization checks.
- Updated build validation and documentation.

### Install
Foundry VTT 13+ (declared verified through 14); RMU 1.3.55 (declared baseline).

**Manifest:** https://raw.githubusercontent.com/Blackbiji/merp-ui/main/module.json

Download the attached `merp-ui-1.6.0-rc.4.zip` file. It contains the `merp-ui/` directory ready for Foundry.
