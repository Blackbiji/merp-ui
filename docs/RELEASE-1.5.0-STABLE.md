# MERP-UI 1.5.0 — Stable

**Compatibilité de référence : RMU 1.5.33**

Cette version est la promotion directe de `1.5.0-rc.3`, sans changement
fonctionnel.

## Référence stable

- MERP-UI : `1.5.0`
- RMU : `1.5.33`
- Statut : **Stable**

Cette version devient la baseline de référence pour les développements
ultérieurs de MERP-UI.

## Architecture

Les cinq passes de refactor sont intégrées :
1. infrastructure dossiers/localisation/migrations ;
2. Spell Lists ;
3. Langues, Herbes, Talents & Défauts ;
4. contrôleur/orchestrateur ;
5. migration unique 1.4.x → 1.5.

La RC.3 validée est conservée à comportement identique.
