# MERP-UI — Changelog

## 1.6.0-rc.4 — Public review candidate (October 2026)

- Improved readability and reduced heading size in character-creation Talent descriptions in French and English.
- Localized more herb forms, seasonal windows, lunar dates and rain-dependent harvest conditions without changing underlying RMU values.
- Confirmed bilingual catalogue coverage of **187 Herbs & Substances** and introduced seven French display-name translations.
- Rebuilt deterministic Compendium bootstrap seeds and content synchronization metadata; maintained nine Compendiums and **455 document identifiers**.
- Updated manifest, runtime version, documentation and release CI for RC4.
- Retained Compendium-first architecture and compatibility baseline with RMU 1.3.55.

This release is an unofficial, non-commercial fan project. Please report bugs and translation issues through the GitHub issue tracker.

## 1.6.0-rc.3 — October 2026

- Consolidated Compendium-first content and the prior FR/EN localization work.
- Published nine permanent Compendiums under MERP-RMU.

## 1.6.0-rc.1 — August 2026

- Introduced the Compendium-first architecture, bilingual content and settings, age-aware Race/Culture options and the installation guide.

Older implementation history is retained in Git.
