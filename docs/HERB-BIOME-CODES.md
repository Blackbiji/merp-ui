# Herb habitat codes / Codes des biomes des herbes

**Source / Source :** *MERP Character Creation Using RMSS/RMFRP v2.5*, section **Enchanted Herbs**, printed p. 206 (PDF p. 208).

The historical herb location code is **climate – terrain – finding difficulty – geographic distribution**, for example `a-Z-5-U`. The letter case matters: a lower-case first letter describes climate, while the terrain and region use upper-case codes. Some entries omit the final region, and others use an exceptional place name instead. **MERP-UI does not reconstruct missing data.**

Un code historique de récolte se lit **climat – terrain – difficulté de découverte – aire géographique**. L'exemple `a-Z-5-U` correspond à un climat aride, au désert, à une difficulté « Difficile » et à une présence dans l'ensemble d'Endor. Certaines entrées sont incomplètes : les champs manquants demeurent « Non précisé ».

### Climate / Climat
`a` aride / arid; `c` froid / cold; `e` froid permanent / everlasting cold; `f` glacial / frigid; `h` chaud et humide / hot and humid; `m` tempéré doux / mild temperate; `s` semi-aride / semi-arid; `t` tempéré frais / cool temperate.

### Geographic region / Aire géographique
`N`, `NW`, `NE` : Nord / North, Nord-Ouest / Northwest, Nord-Est / Northeast; `S`, `SW`, `SE` : Sud / South, Sud-Ouest / Southwest, Sud-Est / Southeast; `E` Est / East; `W` Ouest / West; `M` Centre / Mid-Endor; `U` Ensemble d'Endor / Universal.

### Historical discovery difficulty / Difficulté historique
`1` Routine (+30); `2` Facile / Easy (+20); `3` Aisée / Light (+10); `4` Moyenne / Medium (+0); `5` Difficile / Hard (−10); `6` Très difficile / Very Hard (−20); `7` Extrêmement difficile / Extremely Hard (−30); `8` Pure folie / Sheer Folly (−50); `9` Absurde / Absurd (−70).

**Important / Important :** These numbers summarize the source table; they are informative only. MERP-UI leaves RMU item statistics, difficulty values and rolls unchanged.

In Foundry, open an Herb Item and activate the **ⓘ** icon alongside **Biome(s)**. Hover or focus shows a quick contextual explanation; click to reveal a four-field description, then expand the complete legend if needed. The control is bilingual in the MERP-RMU Content Language setting.

Dans Foundry, ouvrez la fiche d'une herbe et utilisez l'icône **ⓘ** placée à côté de **Biome(s)**. Le survol affiche une synthèse ; un clic ouvre les quatre informations de la plante, puis la légende complète, sans modifier les données RMU.
